# dpi-direns-oauth

Páginas públicas de identificação do aplicativo **Assistente DPI DIRENS**, exigidas pelo Google
para publicar um cliente OAuth (o botão *Publish app* só libera com home, política de privacidade e
termos preenchidos).

- `index.html` — descrição do aplicativo
- `privacidade.html` — política de privacidade
- `termos.html` — termos de uso

Uso interno. Nenhum dado pessoal, credencial ou informação institucional sensível é publicado aqui.
